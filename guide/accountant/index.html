Getting started / Accountant

The accountant guide.

Set up fees, prepare the month’s bills, then review collections.

1. Set fee types and grade fees

  1. Select the Accountant dashboard and the intended School Session.
  2. Open School Fee Type to maintain the school’s fee items.
  3. Open Grade Fee and choose a grade. Set each fee amount, frequency and applicability.
  4. Use the grade-wise student fee view when an individual student needs a different fee amount.

2. Generate monthly bills

  1. Open Claim Bills → Create Monthly Claim Bill.
  2. Search using the school session, grade and month.
  3. Select the fee types and students to include. Review the fee amounts and selection.
  4. Choose Generate Claim Bill, then review the generated bills.
Review before generatingConfirm the academic session, grade, month and selected students each time. The demo amounts shown are fictional.

3. Finalize and print selected bills

  1. Open the monthly bills for the intended grade and month.
  2. Review bill items and totals. Finalize a bill once it is ready.
  3. Select the bills to print using their checkboxes.
  4. Choose Print Selected Bills. The print-options menu also offers Print Carbon Copy and Print Compact (4-up).
  5. Check the browser print preview and printer settings before printing.

4. Record a payment

  1. Open a finalized bill and choose its payment action.
  2. Enter the payment details, amount and any applicable discount using the school’s process.
  3. Save, then review the bill’s paid and pending amounts. Use Paid Bills to find payment records.

5. Review fee collections

  1. Open Fees Collection Report.
  2. Select the relevant session and date range, with grade and other filters as needed.
  3. Run the report and inspect the detailed entries.
  4. Use the CSV export when you need to work with the report outside the application.
