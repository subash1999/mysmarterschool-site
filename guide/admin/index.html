Getting started / School admin

The school admin guide.

Set up the academic year, then connect the people and classes.

1. Create and select a session

  1. Open School Sessions → Create School Session.
  2. Enter a Session Name, From Date and To Date, then create the session.
  3. Choose that session in the sidebar School Session selector before working on grades, students or exams.
Check the selected sessionAll Sessions can combine records from different years. Choose the intended year before starting setup.

2. Add grades and subjects

  1. Open Grades → Create Grade. Select the session, enter the grade and add a section if needed.
  2. Open Subjects and create the required subject records, including names and subject codes.
  3. Open a grade record and add its subjects from the available subject list.

3. Add teachers and assignments

  1. Open Teachers → Create Teacher. Associate a user account and complete the required teacher details.
  2. Open the relevant subject or grade-subject record and assign the teacher.
  3. Check that the teacher can select the Teacher dashboard and find the assigned subjects.

4. Register students and guardians

  1. Create guardian records for the people who will use guardian access.
  2. Open Students → Create Student. Enter the required student details, grade and roll number.
  3. Choose a guardian and relationship where applicable, then save the record.
  4. Return to the student list to verify the grade and guardian links.

5. Set up examinations

  1. Open Exam Groups and create an examination group in the intended session.
  2. Add the participating grades, then the subjects and marking details for each grade.
  3. Set the result publication date and time. Teachers can then enter marks in their area.

6. Add dates to the calendar

  1. Open School Calendar.
  2. Add a school event with its text, start date and end date.
  3. Review the event in the calendar and update it when the schedule changes.
